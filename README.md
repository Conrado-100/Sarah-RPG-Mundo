# 🎲 Forja de Idiomas - Gerador RPG

Bem-vindo à Forja de Idiomas! Este é um aplicativo web desenvolvido especialmente para auxiliar Mestres de RPG na criação de *worldbuilding* imersivo. Ele gera nomes e línguas fictícias respeitando a regra fonética de cada cultura, rodando inteiramente de forma local e offline no seu navegador.

---

## 🎲 Sobre o Projeto

O objetivo deste gerador é fugir de "letras aleatórias" e criar palavras que soem naturais para a cultura escolhida no seu mundo de fantasia. Seja para nomear um NPC rápido no meio da sessão, uma cidade antiga ou um artefato mágico, a Forja resolve isso em segundos.

---

## ✨ Funcionalidades

*   **Sotaques Personalizados:** Geração fonética para 8 culturas diferentes (Comum, Élfico, Orc, Anão, Celestial, Abissal, Feérico, Cyberpunk).
*   **Significados Direcionados:** Sorteio automático de significados baseados no contexto (Pessoa, Lugar, Artefato ou Geral).
*   **Histórico de Sessão:** Uma memória interna que salva todos os nomes gerados enquanto você usa o aplicativo.
*   **Exportação Offline:** Salve seu histórico em um arquivo `.txt` diretamente pelo navegador, sem precisar de internet ou banco de dados.

---

## 🚀 Como Executar (Passo a Passo)

O sistema não exige instalações complexas. Para usá-lo no celular ou no computador, siga os passos abaixo:

*   **Passo 1:** Faça o download deste projeto clicando no botão verde **Code** > **Download ZIP** (ou utilize o arquivo `.zip` enviado diretamente para você).
*   **Passo 2:** Extraia o arquivo `.zip` usando o gerenciador de arquivos do seu celular (ex: Files do Google) ou computador.
*   **Passo 3:** Navegue até a pasta `logica` e abra o arquivo `index.html`.
*   **Passo 4:** O sistema pedirá para abrir com um navegador (Chrome, Safari, Edge, etc.). Escolha o seu favorito e o gerador estará pronto para uso!

---

## 💡 Dicas de Uso

*   O gerador funciona 100% sem conexão com a internet.
*   Atenção: O histórico é reiniciado se você fechar a aba do navegador. Lembre-se sempre de clicar em **💾 Exportar** para salvar seus nomes favoritos em um arquivo de texto antes de sair!
